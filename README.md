# Aditya Raj — Premium App Developer Portfolio

## Run
Open `index.html` in a browser.

## Customize first
1. Replace the profile placeholders with your real photo.
2. Replace the CSS phone mockups with screenshots of Study Saathi / Startly / other apps.
3. Change project links, GitHub, LinkedIn and email links.
4. Add your real `resume.pdf` and change the Download Resume link.
5. Update stats and experience with verified numbers.

## Scroll behaviour included
- Sticky blurred navbar
- Active navigation section while scrolling
- Smooth anchor scrolling
- Scroll-triggered reveal animations
- Hover lift animations on cards/phones
- Mobile navigation drawer
- Back-to-top button
- Light/dark theme toggle
- Responsive desktop/tablet/mobile layout
- Subtle cursor glow on desktop
